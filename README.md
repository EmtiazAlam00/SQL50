# SQL50

My solutions to the [LeetCode SQL 50](https://leetcode.com/studyplan/top-sql-50/) study plan.ssss

## About

SQL 50 is a set of 50 SQL problems on LeetCode. It covers core database skills like querying, joins, aggregation, subqueries, and string and date functions. This repo is where I keep my answers as I work through them.

## Structure

All solutions are in [`SQL50.sql`](SQL50.sql). Each answer has a comment above it with the problem's number and title.

## Topics

- Select
- Basic Joins
- Basic Aggregate Functions
- Sorting and Grouping
- Advanced Select and Joins
- Subqueries
- Advanced String Functions / Regex / Clause
